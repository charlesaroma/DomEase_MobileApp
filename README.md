# DomEase mobile app

DomEase (Domestic Ease) for iOS and Android: meals, cleaning and one shared shopping list for Ugandan homes. Flutter, Riverpod and go_router; the API is Node.js with MongoDB and Prisma.

```bash
flutter pub get
flutter run
flutter test
```

Start with [docs/README.md](docs/README.md).

Built by Raijin Tech Hub Co. Ltd (SMC), Kampala.
